# Project Rules - React Report

## Tech Stack
- React 19 with TypeScript
- Vite 7 for build tooling
- Tailwind CSS 4 for styling
- Framer Motion for animations
- AOS (Animate On Scroll) for scroll animations
- Lucide React for icons

## Code Style
- Use functional components with hooks
- Prefer TypeScript strict typing
- Use Tailwind CSS utility classes for styling
- Keep components modular and reusable

## Project Structure
- Components go in `src/components/`
- Custom hooks go in `src/hooks/`
- Static assets go in `src/assets/`

## UI/UX Guidelines
- All user-facing text must be in Chinese (中文)
- Use glass-card styling for card components
- Maintain dark theme with gradient accents (sky, violet, purple)
- Include smooth animations and transitions

## Commands
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
